# Mechanical Engineering Portfolio

A responsive personal portfolio website for a mechanical engineering student.

## Features

- Responsive desktop/mobile layout
- Engineering-inspired blueprint visuals built with CSS
- Projects, skills, education, experience, and contact sections
- Mobile navigation
- Scroll reveal animations
- Downloadable resume link
- No framework or build step required

## Customize it

Open `index.html` and replace:

- `Alex Morgan` with your name
- University and degree information
- GPA / project / internship statistics
- Project descriptions and links
- Skills and software
- Email, LinkedIn, and GitHub URLs

Place your actual resume at:

`assets/resume.pdf`

You can also replace the CSS-generated project illustrations with your own project images.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `mechanical-engineering-portfolio`.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://YOUR-USERNAME.github.io/mechanical-engineering-portfolio/`
